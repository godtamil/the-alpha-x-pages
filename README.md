# THE ALPHA X — GitHub Pages frontend

This repository publishes the public website at `https://godtamil.github.io/the-alpha-x-pages/`.

GitHub Pages serves the HTML, CSS, and JavaScript. Applications are sent over HTTPS to the THE ALPHA X API hosted on Sites, where they are stored in the database. The admin link opens that site's protected dashboard. No admin credentials or applicant data are stored in this repository.
