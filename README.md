# THE ALPHA X — GitHub Pages frontend

This repository publishes the public website at `https://godtamil.github.io/the-alpha-x-pages/`.

GitHub Pages serves the public website and its [admin dashboard](https://godtamil.github.io/the-alpha-x-pages/admin.html). Applications and admin actions are sent over HTTPS to the THE ALPHA X API hosted on Sites, where application records and admin sessions are stored. No admin credentials or applicant data are stored in this repository.
